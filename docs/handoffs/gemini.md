# הודעה להעברה ל־Gemini

עדכון ערוץ תקשורת: המשתמש ביקש תיאום ישיר ב־`TEAM_CHAT.md` של ה־checkout
הראשי. קרא אותו באמצעות `python scripts/team_chat.py read`, אשר קבלה וענה
שם ל־Codex ול־Claude. פרטים ב־`docs/team-chat.md`; אין צורך בתיווך המשתמש.

אנחנו עובדים בצוות של שלושה בוטים על Project Noesis. המשתמש מינה את Codex
לרכז את העבודה וחילק לך את תחום **הגוף, המדידה ואימות התוצאות**.

המשימה שלך: https://github.com/amithey/Project-Noesis/issues/20

קרא את `AGENTS.md` ואת `docs/team-training-plan.md` בענף
`codex/github-project-sync`, ואת התוכנית המדעית `gpu-pilot/training-plan.md`.
אשר קבלת המשימה ב־#20 וציין את הענף ואת SHA הבסיס. עבוד ב־checkout נפרד
בענף `gemini/flygym2-gait-validation`; אם כבר נוצר, השתמש בו לאחר בדיקה.

התחל מ־gait_metrics.py חדש ומהרחבת evaluate.py: מחזורי תמיכה/הרמה לכל רגל,
התקדמות בכיוון הגוף, החלקה ו־tripod. בדוק עמידה סטטית, החלקה/גרירה, רעד
מגע ונפילה מול צעדים אמיתיים. שמור את ממשקי ההערכה הקיימים, ודחה נתונים
חסרים, פרקים חלקיים והשוואות לא תואמות במקום להפיק מהם הצלחה.

שחזר את דוחות 10006/10007 עבור ההורה והמועמד מקובצי ה־Release
`training-backup-2026-10-27`. הוראות השחזור והחתימות ב־`docs/coordination.md`.
התוצר הראשון הוא PR של מדדים, בדיקות סינתטיות ודוח שחזור; הוא אינו דורש
ריצת אימון חדשה. חושים/מכשולים ואימות NVIDIA יבואו בשלב הבא.

Codex אחראי למנהל האימון, לסביבה, לשילוב ולמשקולות המשותפות. Claude
אחראי ללמידה ולתגמולים. אל תשנה learning.py, train.py או ספי הצלחה.
אין לקדם מודל על סמך תגמול גבוה, תזוזה בלבד או פרק שנקטע.

דחוף תוצרים ופתח PR ל־`codex/github-project-sync` עם בדיקות, commit וחסמים.
עדכן את #20 ואת #17 כשיש תלות בבוט אחר. ריצת מוח מלאה על המחשב המשותף
מתואמת עם Codex; כל פלט ומועמד נשמרים בתיקייה עצמאית.
