# הודעה להעברה ל־Claude / Anthropic

אנחנו עובדים בצוות של שלושה בוטים על Project Noesis. המשתמש מינה את Codex
לרכז את העבודה וחילק לך את תחום **המוח, הלמידה והתגמולים**.

המשימה שלך: https://github.com/amithey/Project-Noesis/issues/19

קרא את `AGENTS.md` ואת `docs/team-training-plan.md` בענף
`codex/github-project-sync`, ואת התוכנית המדעית `gpu-pilot/training-plan.md`.
אשר קבלת המשימה ב־#19 וציין את הענף ואת SHA הבסיס. עבוד ב־checkout נפרד
בענף `claude/flygym2-learning-rewards`; אם כבר נוצר, השתמש בו לאחר בדיקה.

התחל מהתאמה ובדיקה של מטרות התגמול הקיימות v7/v8/v6 ב־learning.py ובמודול
reward_profiles.py חדש. שמור את API התגמול ואת ברירת המחדל, ובדוק טעינה,
שמירה, חסמים ביחס למקור, סימני חיבור, טופולוגיה וחקירה כבויה בהערכה.
בדיקות סינתטיות ומיפוי הממשק ל־Codex הם התוצר הראשון; אין צורך לחכות לריצה.

ליבת המוח הנדרשת: `codex/brain-body-feedback` ב־
`41b5fe6534ed4c8f0c21a2e123c8d518b3bf5953`, ב־checkout נפרד.
המשקולות והראיות ב־Release `training-backup-2026-10-27`; הוראות השחזור
והחתימות ב־`docs/coordination.md`. אל תשתמש בליבת ה־hub הישנה בטעות.

Codex אחראי ל־runner, לשמירה, לשילוב ולמשקולות המשותפות. Gemini אחראי
לגוף ולמדדים. עבוד רק בקבצים שהוקצו לך; שינוי core הכרחי מוגש בענף/PR נפרד
לפי התוכנית. אין לשנות את ספי ההצלחה או להחליף כלל למידה תוך כדי ההעברה.

דחוף תוצרים ופתח PR ל־`codex/github-project-sync` עם בדיקות, commit וחסמים.

מתואמת עם Codex; כל פלט ומועמד נשמרים בתיקייה עצמאית.
