# מסירה למחשב המקורי: הנתונים שחסרים להמשך אימון Noesis

עודכן: 4 בנובמבר 2026. מיועד לסוכן/למפעיל שמחזיק בתיקיית Project Noesis המקורית.

## הפעולה הנדרשת ממך

להעביר למחשב השני את **ארבעת קובצי הקונקטום המקוריים** המפורטים למטה, בערוץ פרטי המותר לפי רישיון הנתונים, ולמסור את הנתיב שבו נשמרו בפועל. המחשב השני כבר מחזיק בקוד, בסביבת Python/FlyGym ובמשקולות; אין צורך להעביר אותם שוב.

**D:\NoesisData הוא נתיב יעד מוצע בלבד. כרגע התיקייה הזו אינה קיימת במחשב השני.** יצירת תיקייה ריקה או שליחת הקישור לגיטהאב לא פותרות את החסם: צריכים להיות בה הקבצים עצמם.

## איך למסור ולדווח חזרה

1. אתר את ארבעת הקבצים במחשב המקורי ואמת את החתימות.
2. העבר אותם באופן פרטי למחשב השני ושמור את המבנה לעיל. **לא להעלות את הנתונים או קאש נגזר ל־Git או ל־GitHub Releases ציבוריים.**
3. אם אין לך גישה למחשב השני, מסור למשתמש ארכיון פרטי או העתק מקומי להעברה. אין לטעון שהנתונים הועברו לפני שנבדקו ביעד.
4. דווח כאן בגיטהאב או למשתמש: הנתיב המוחלט ביעד, האם ההעתקה הושלמה, גודל כל קובץ ותוצאת אימות ארבע החתימות. אין למסור סיסמאות או tokens.
5. אם הנתונים כבר נמצאים במחשב השני במקום אחר, מספיק למסור את הנתיב המוחלט המדויק.

תגובה מועילה לדוגמה:

```text
ההעברה למחשב השני הושלמה.
נתיב הנתונים בפועל: <נתיב מוחלט>
ארבעת הקבצים קיימים והחתימות תואמות: כן/לא
אם לא: פירוט הקובץ והחתימה שנמצאה.
```

## מה כבר מוכן במחשב השני

- Python 3.12.14, FlyGym 2.1.0 והתקנת MuJoCo מקומית.
- Pilot runtime: `75cdc34aeeacb7684c73b6e91bd39fddf399cc9f`.
- Core runtime: `42c20769376bda5694b4c1c66ca75e52cbd9f1f4`.
- הורה אימון שלם, עם SHA-256 מאומת:
  `9fd7d41177bf2c745809401c3b142a832661d1a18d0b117b30cb02aea63fea3c`.
- 21 בדיקות אבחון עברו; בדיקת גוף ניטרלי קצרה עברה. אלה אינן הוכחת הליכה או בדיקת מוח מלאה.
- הקאש אינו חובה: הקוד יכול לבנות אותו בתיקיית הפלט לאחר שקובצי המקור זמינים.

## הכשל הנוכחי והמשך העבודה

בדיקת הטעינה הקפואה עם `--data D:\NoesisData` נעצרה לאחר 7.891 שניות עם:

```text
status: failed
FileNotFoundError: MANC is required for the corrected training brain
completed_control_chunks: 0
```

כל ארבעת הקבצים חסרים בנתיב היעד; שגיאת MANC היא הבדיקה הראשונה שנכשלה, לא הוכחה שרק MANC חסר. המשקולות לא שונו ונעילת ההרצה שוחררה.

לאחר ההעברה, הסוכן במחשב השני יאמת את החתימות ויריץ את בדיקת הטעינה שבמדריך: CPU, זבוב אחד, 0.1 שניות סימולציה, seed10006, עד600 שניות עבודה, ללא למידה/חקירה. מעבר דורש השלמת20 צעדי בקרה ותאימות המשקולות. אין להתחיל אימון כבד או לקדם מודל רק על סמך מסירת הקבצים.
